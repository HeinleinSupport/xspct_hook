# Contributing

## Commit messages

This project uses [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) for all
commit messages, from the first commit onward.

### Format

```
<type>(<scope>): <description>

[optional body]

[optional footer(s)]
```

### Types

| Type | When to use |
|------|-------------|
| `feat` | New functionality |
| `fix` | Bug fix |
| `docs` | Documentation only |
| `refactor` | Restructuring without behavior change |
| `test` | Test-only change |
| `perf` | Performance improvement |
| `build` | Build system, dependencies, `pyproject.toml` |
| `ci` | CI configuration |
| `chore` | Other maintenance |

### Scopes

| Scope | Area |
|-------|------|
| `protocol` | Canonical -01-shaped domain model (contexts, actions, modifications, decisions) |
| `wire` | `StalwartCodec` / `Mta01Codec` wire-format translation |
| `adapter` | Individual scan adapters (`PseudoScannerAdapter`, `ClamAVAdapter`, `XspctScanAdapter`) |
| `orchestrator` | `HookOrchestrator` and aggregation strategies |
| `app` | FastAPI app, routing, and Bearer-token authentication |
| `body` | `MessageBody`: in-memory and spooled message content |
| `events` | `EventBus` and the JSONL event log |
| `registration` | In-memory registration store of the native -01 endpoint |
| `testing` | Bundled `Mta01TestClient` and the smoke-test demo |
| `config` | Configuration schema, profiles, adapter/strategy registry, and defaults |
| `cli` | Command-line entrypoint |

### Breaking changes

Mark with `!` after the scope (e.g. `feat(wire)!: ...`) and/or a
`BREAKING CHANGE:` footer.

### Rules

- Description in the imperative mood, lowercase, no trailing period.
- First line preferably at most 72 characters; hard limit 100.
- Body is optional, separated from the header by a blank line.
- Footers (after a blank line): `Refs:` for plan/issue links and `Tests:` for
  the tests actually run with their result, for example
  `Tests: pytest: 412 passed, 0 skipped`, or `Tests: not run (<reason>)`.
- **All commits and tags must be GPG-signed:**
  ```bash
  git commit -S -m "feat(adapter): add ClamAV INSTREAM support"
  git tag -s X.Y.Z -F <notes-file>   # "X.Y.Z", blank line, changelog bullets
  ```
- **Never** include "generated by", "co-authored by", or any AI attribution
  in commit messages.
- Independent changes are committed separately — don't mix an adapter
  extension with a protocol-layer change in the same commit.
